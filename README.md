# Wireless-Attack-and-Defense-Demonstration-Lab
An interactive IEEE 802.11 wireless security simulation lab built with Flask, HTML5 &amp; SVG. Demonstrates 4 real attack vectors (Deauth, Evil Twin, WPS Brute Force, PMKID) and 4 live defense mitigations (802.11w MFP, WPA3-SAE, WPS Disablement, WIDS) with real-time frame dissection and animated packet telemetry.
